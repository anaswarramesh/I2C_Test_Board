# I2C_Test_PCB

PCB for an I2C breakout board.
Dedicated space for an ESP32 S3 Zero board and an OLED display.
From ESP 32 pin 7 and pin 8 are connected to top male headers.
Pin 7 as SCL and Pin 8 as SDA
Top 20 male header for SDA and bottom 20 male header for SCL.
5V and 3V pins of ESP32 are also connected to  male header.

## Overview

This repository contains the PCB design files for an I2C breakout board project.
Simply program the ESP32 to display on the onboard OLED screen.
More number of I2C sensor boards can be connected to the SDA,SCL and 5V pin.


## Contents

- PCB design files
- I2C display support
- Schematic / layout assets
- Supporting project files

## Notes

Currently there are places for 2 ESP32 mini boards, place for one can be replaced to place 2 ultra mini breadboard.
User can utilise either left or right postion for ESP32 and other one for ultra mini breadboard.
